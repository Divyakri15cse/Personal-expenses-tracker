Personal Expense Tracker

A simple Python-based Personal Expense Tracker that helps users record, view, search and manage their daily expenses.

Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Search expenses by category
- Delete expenses
- Store data using file handling
- Basic error handling for invalid inputs

Technologies Used

- Python
- File Handling
- Functions
- Loops
- Lists
- Exception Handling

How to Run

1. Download or clone the repository.
2. Open "expense_tracker.py".
3. Run the Python program.
4. Select an option from the menu.

Project Purpose

This project was created to practice Python programming concepts such as functions, loops, file handling, data processing and exception handling.
